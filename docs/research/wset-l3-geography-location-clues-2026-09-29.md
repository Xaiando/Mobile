# WSET Level 3 geographic location clues — 29 September 2026

The [WSET Level 3 Award in Wines specification, Issue 2](https://www.wsetglobal.com/media/11731/wset_l3wines_specification_en_highres_may2022_issue2.pdf), Unit 1 Learning Outcome 2, names principal still-wine regions and asks candidates to locate them and explain relevant production factors. These are original study prompts, not WSET examination questions or a claim of complete Level 3 preparation.

## Gap and design audit

The `c94a421` release has **35 WSET_L3 core geography `LOCATED_IN` items** served by `map_locate`, `map_identify` and `map_pair` but lacking a second objective family under the existing useful-practice rule. The new `authored_choice` template covers exactly those 35 IDs. Prompts ask for a geographic parent using a different kind of clue as appropriate: neighbouring countries and coastlines, official wine-register groupings, appellation-area departments, nested regional names, and AVA county entries. The four options in each item are peer places or jurisdictions, including nearby or easily confused regions rather than non-geographic statements. The answers occupy positions 0–3 in a **9/9/9/8** balance; none is the sole longest or shortest option, no option uses an absolute-word cue, and no prompt repeats the complete keyed answer. The existing click-map formats and map geometry are untouched.

Each clue cites a source attached to its specific item. The Schlossböckelheim item gains a second link to the existing Deutsches Weininstitut seminar handbook because it explicitly locates the village at the middle/upper Nahe transition. Four Burgundy items gain links to the existing regional wine board source so their prompts can ask about actual vineyard locations rather than translate “Bourgogne” into “Burgundy.” The 35 items now have **44 item-to-source links across 25 source URLs**; the authored clues select **23 distinct primary URLs**. Item assertions and certification mappings remain unchanged, and every item remains `unverified`.

## Measured result and review status

With the provisional `0.24.34` release, WSET_L3 geography core useful practice rises from **1,014 to 1,049 of 1,060**. All **35/35** spatial-only core `LOCATED_IN` gaps close while the geography spatial count remains **1,673**. The **11** remaining geography core-practice gaps are eight `PRINCIPLE_EXPLANATION` and three classification items. These counts measure available practice under the app's format policy, not verified factual accuracy, map skill mastery, tasting competence or award readiness. A wine educator should review the geographic clue wording and the existing source-to-item inferences before changing `verification_status`.
