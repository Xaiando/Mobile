# D6 learner research workspace review

The [WSET Level 4 Diploma in Wines specification, Issue 1.4 (2025)](https://www.wsetglobal.com/media/17609/wset_l4wines_specification_en_august-2025.pdf), p. 18, defines D6 LO 6.1 as researching a specified wine subject. Its three assessment criteria concern relevant source material, evaluating sources to build an argument and conclusion, and following the issued brief's presentation requirements. The official assessment is an external 3,000-word assignment. This app does not bundle current WSET titles, submit a paper or assess one.

The D6 unit in WSET progress opens a private workspace. The learner enters their own topic and brief, then saves an outline, subquestions, an appraised source log, claims linked to those sources, counterevidence, conclusions, a free-form draft and a revision checklist. The draft shows an approximate live count for that field only. The learner must check the issued brief for the actual word-count and reference rules. A text export includes the saved work for tutor feedback, labelled formative and ungraded. Saving a nonempty workspace appears as draft participation in D6 progress; it cannot set an exam pass, a curriculum milestone, or spaced-review credit.

One workspace is stored under `d6_research_workspace_v1` in `user_settings`. The existing version-2 user-data backup includes all settings, so it exports and restores the draft without a database migration. The model validates schema version, UUIDs, UTC timestamps, linked source IDs, checklist keys, record counts, field lengths and snapshot size. A malformed or newer value is shown as unreadable and is never silently overwritten. Explicit recovery moves its raw value to a backed-up recovery key before starting fresh. Reopening after a crash uses the last committed edit. Screen writes are serialised, navigation waits for them, and a failed edit blocks export or exit until the learner deliberately reloads the saved copy. The file export itself is unencrypted; the learner chooses where to save it.

This remains a preparation tool. It does not provide WSET's released title, tutor feedback, originality checks, reference-style verification, a complete assignment submission package or examiner judgement. Source dates and URLs are learner-entered notes rather than verified citations. The word counter is approximate and deliberately does not claim compliance with any issued brief.
