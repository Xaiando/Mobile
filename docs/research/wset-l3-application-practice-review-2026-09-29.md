# WSET Level 3 application practice, release 0.24.11

This release registers 40 original four-option application questions on existing core facts: 27 regional growing and style decisions, seven vineyard/winery decisions, and six sparkling/fortified decisions. The cases ask for a bounded consequence or comparison from stated evidence, not a universal quality ranking. All target facts are Level 3 core and had no useful practice before this batch. Fifteen also carry Level 2 core mappings, so their bounded questions serve both levels; the source-linked selection and track behavior are checked by the authored-choice regression.

The [WSET Level 3 Wines specification, 2022 Issue 2](https://www.wsetglobal.com/media/11731/wset_l3wines_specification_en_highres_may2022_issue2.pdf) defines the teaching scope. The keyed answers use linked primary regional, regulator, university-extension or technical sources rather than copying WSET examination language. Direct checks include [Bourgogne's climate account](https://www.bourgogne-wines.com/wine-and-terroir/our-natural-assets/climatology/an-ideal-climate-for-producing-great-wines,2483,9268.html), [Beaujolais semi-carbonic practice](https://www.beaujolais.com/en/discover/know-how/the-grower-s-work/), [Wines of Greece's Nemea account](https://winesofgreece.org/pdo/pdo-nemea/), [Wine Australia's Hunter Valley account](https://www.wineaustralia.com/market-insights/regions-and-varieties/new-south-wales-wines/hunter-valley), [AWRI's extended-maceration explanation](https://www.awri.com.au/industry_support/winemaking_resources/winemaking-practices/winemaking-treatment-extended-post-fermentation-maceration/), [Prosecco DOC production rules](https://www.prosecco.wine/en/prosecco/production-regulation/), [DO Cava's grape guide](https://www.cava.wine/en/origin-cava/authorised-grape-varieties/) and [Taylor's Port production account](https://www.taylor.pt/en/what-is-port-wine/how-is-port-made). The red post-fermentation question now cites the already registered direct AWRI source, not the older Penn State tag archive. The template records a source ID for every answer; the curriculum citation record supplies its locator.

Each target has one item-specific cited answer, four distinct options, and balanced answer positions (10 per position). No keyed answer is the uniquely longest or shortest option. Curriculum lint passes 159 included files with zero errors and three existing curator warnings; the focused app tests pass **29/29**, and `flutter analyze --no-pub` passes. Updating the strict coverage baseline raises useful **core** practice from **1,179/2,228 to 1,219/2,228** at Level 3 and **520/744 to 535/744** at Level 2; CMS Certified rises from **785/1,221 to 812/1,221**. Level 1 remains **132/132**. These are app practice counts, not WSET qualification or exam-readiness measures. Core causal reasoning remains zero at Levels 2 and 3. All 4,125 knowledge items remain `unverified` pending qualified educator review. The full app regression and browser release smoke remain pending for this release.
